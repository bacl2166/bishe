# 实验一实现计划

用户已授权实现并通过 SSH 提交到 bacl2166/bishe。

目标是在固定商品评分下，比较全部候选商品编码面对购物筛选时的分布偏移、搜索遗漏、推荐质量及成本。

- 数据与请求模块负责训练期目录、时间划分、已核验属性、训练期口碑和独立规则种子。
- 编码模块统一返回唯一 item-to-token 路径，说明论文核心模块适配与原生系统的差异。
- 评分模块训练 MostPopular、ItemKNN、SASRec，每份商品概率由所有编码共享。
- 搜索模块实现原概率保留、逐步合法路径重新归一化和完整可行概率质量参照。
- 每种方式都枚举相同完整路径评分的精确排名，避免将目标变化误认为搜索损失。
- 输出逐请求结果、匹配成本曲线、HR/NDCG、命中丢失与新增、两套参考召回、KL、剪枝和计算量。
- 固定用户与请求，独立变化评分器和编码种子，用户级配对 bootstrap。
- 在临时小样本验证整个CLI，并与手算四商品概率和充分搜索的枚举结果核对。
- 交付完整服务器配置、数据下载、断点复跑说明及 GitHub 提交。
